## Current repository scope

This repository supports the revised continuous-program DLBCL manuscript. Historical versioned releases and tags remain immutable.

It includes:

- the six-program continuous framework and recorded membership provenance;
- released derived inputs and machine-readable source data associated with Figures 1-6 and Supplementary Figures S1-S6;
- harmonized bulk-scoring, model-form, orthogonal benchmark, exploratory continuous-program survival, and spatial sensitivity summaries;
- current analysis and figure-generation scripts;
- the retained R lockfile, exact package-version evidence, seed records, and current-tree integrity/provenance manifests.

Publication-ready main figures, supplementary figures, and the compiled Supplementary Tables workbook are distributed with the journal submission/publication and are not duplicated in the current repository tree.

The validated historical GSE31312 score matrix is released as a derived input. Its original package environment cannot be reconstructed exactly, so exact raw-to-historical-score regeneration is not claimed. Modern harmonized sensitivity analyses use the documented current environment.

No candidate k from 2-6 was sufficiently stable under the full retention rule set. Final k was not selected, and no discrete ecosystem taxonomy was assigned.
