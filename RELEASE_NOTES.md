# Version 1.0.0

This first versioned public release supports the revised continuous-program DLBCL manuscript.

It includes:

- the six-program continuous framework and recorded membership provenance;
- frozen derived inputs and source data for Figures 1-6 and Supplementary Figures S1-S6;
- reviewer-requested harmonized bulk-scoring, model-form, orthogonal benchmark, exploratory continuous-program survival, and spatial sensitivity summaries;
- current analysis and figure-generation scripts;
- the retained R lockfile, exact package-version evidence, seed records, and release manifests; and
- the final Frontiers submission-ready Supplementary Tables workbook.

The historical GSE31312 score matrix is released as a frozen authority. Its original package environment cannot be reconstructed exactly, so exact raw-to-historical-score regeneration is not claimed. Modern harmonized sensitivity analyses use the documented current environment.

No candidate k from 2-6 was sufficiently stable under the full retention rule set. Final k was not selected, and no discrete ecosystem taxonomy was assigned.
